# Triage labels

As skills trabalham com cinco funções canônicas de triagem. Este arquivo associa cada função à label utilizada no issue tracker deste repositório.

| Função canônica | Label no tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Um responsável precisa avaliar a issue |
| `needs-info` | `needs-info` | Aguardando mais informações de quem abriu a issue |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificada e pronta para um agente |
| `ready-for-human` | `ready-for-human` | Requer implementação ou intervenção humana |
| `wontfix` | `wontfix` | Não será implementada |

Quando uma skill mencionar uma função de triagem, use a label correspondente nesta tabela. As labels permanecem em inglês, mas perguntas, explicações, comentários e demais interações devem ser escritos em português.
